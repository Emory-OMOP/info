# Funded: Software tools for creating standardized multimodal EHR datasets for advancing ophthalmic research using AI

An NIH-funded (R50) effort to build software tools that standardize
multimodal EHR data — notes, structured data, imaging — for AI-driven
ophthalmic research. The multimodal-standardization theme overlaps our
imaging-OMOP and NLP directions.
