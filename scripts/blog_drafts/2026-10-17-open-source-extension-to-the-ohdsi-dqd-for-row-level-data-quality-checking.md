# Open-source extension to the OHDSI DQD for row-level data quality checking

**Source**: [OHDSI Forums](https://forums.ohdsi.org/t/open-source-extension-to-the-ohdsi-dqd-for-row-level-data-quality-checking/26246)
**Matched keywords**: OMOP, OHDSI

Hi everyone,
I am happy to share our work on extending the OHDSI Data Quality Dashboard (DQD) to enable row-level data quality checking.
This allows users to trace a data-quality failure back to the specific OMOP record contributing to the issue and, where available, the underlying source document. This makes it possible to investigate individual records behind an aggregate DQD result and identify where a data-quality issue needs to be addressed.
