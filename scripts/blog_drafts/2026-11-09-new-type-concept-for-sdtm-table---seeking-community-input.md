# New Type Concept for SDTM table - Seeking community input

**Source**: [OHDSI Forums](https://forums.ohdsi.org/t/new-type-concept-for-sdtm-table-seeking-community-input/26399)

This was aligned with our philosophy to use existing terminology as much as possible.  However, we are not actually mapping from the CRF, but rather one step further along in data processing - the SDTM Table.  Value_source_value contains the verbatim reported in the SDTM Table.
