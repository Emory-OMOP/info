# ICU representation in VISIT_DETAIL: community input needed

**Source**: [OHDSI Forums](https://forums.ohdsi.org/t/icu-representation-in-visit-detail-community-input-needed/26369)
**Matched keywords**: OMOP

Hi everyone,
We are seeking community input to move forward with Vocabulary issue #1199, which proposes ICU-specific Standard Visit concepts for VISIT_DETAIL.visit_detail_concept_id.
In CHoRUS, sites use local concepts to preserve ICU distinctions recorded in their source systems. A consistent representation would support patient trajectory analysis and cross-site cohort definitions.
The CDM documentation supports representing a time-bounded ICU stay in VISIT_DETAIL, with an optional link to CAR
